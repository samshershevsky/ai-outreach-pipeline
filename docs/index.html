Architecture

How the system fits together.

One orchestrator agent on Claude coordinates six specialized sub agents. The sub agents never touch tools directly: every call goes through a custom MCP server, and every draft waits for a human before anything is sent.

The middle layer is a custom MCP server named gtm-pipeline-mcp. A sanitized demo of it ships in this repo with four tools, enrich_lead, score_lead, draft_outreach, and get_report, running on the same synthetic leads as the pipeline below.

    Evals and Monitoring

    Every run is checked, not trusted.

    The eval script in this repo runs against all 25 synthetic leads and verifies the pipeline before anyone believes its output. These are the actual results from the latest run, also saved in the repo as evals/results.json. The same evals run in CI on every push.

    25 of 25

    Scoring consistency

    Leads that scored identically across 5 repeated runs each.

    25 of 25

    Rubric correctness

    Scores that match an independent recomputation of the rubric math, with a reason string for every point.

    25 of 25

    Draft grounding

    Drafts that reference at least one real signal from their own lead and invent no facts.

    100%

    Tool call success

    Across 75 tool calls in the eval run. Mean latency 0.013 ms, p95 0.028 ms, measured locally.

    In production, monitoring watches the same failure modes the evals check for: failed tool calls, latency spikes on any agent step, and low confidence scores that suggest a lead was scored on thin data. An alert fires when any of those move, and a human reviews the flagged runs before the next batch of drafts is approved. Nothing sends while a check is red.

    Explainable scoring

    Every point has a reason string. A human or a reviewer agent can audit why a lead is Tier A. Black-box scores don't survive contact with a sales team.

    📝

    Prompts as code review

    Outreach prompts live in versioned files, not buried in logic. Reviewable, diffable, improvable like any other code.

    🤝

    Human-in-the-loop

    The pipeline ends at drafts, not sends. Approval gates are a design choice: AI does the research and writing, humans make the calls.
